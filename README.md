# Algoria

Algoria는 세상에 존재하는 알고리즘과 그 주변 개념을 하나의 거대한 계통도로 탐색하는 정적 웹사이트입니다.

일반적인 알고리즘 위키처럼 글이나 카드를 나열하지 않고, 첫 화면부터 `Algorithm`을 뿌리로 하는 왼쪽에서 오른쪽 방향의 분류도를 보여줍니다. 사용자는 관심 있는 가지를 단계적으로 펼치며 알고리즘의 위치와 발전 관계를 한눈에 살펴볼 수 있습니다.

## 알고리즘을 바라보는 방식

Algoria는 알고리즘 세계를 다음 다섯 종류의 개념으로 구분합니다.

- **Algorithms** — 명확하게 정의되고 실행 가능한 알고리즘
- **Problems** — 알고리즘이 해결하려는 문제
- **Techniques** — 알고리즘을 설계하고 문제를 해결하는 방법론
- **Data Structures** — 알고리즘 구현과 수행에 사용되는 자료구조
- **Domains** — 알고리즘이 속하거나 주로 활용되는 분야

화면에서는 이 개념들이 직관적인 계통도로 표현되지만, 내부 데이터는 분류상의 위치와 실제 의미 관계를 구분합니다. 따라서 하나의 알고리즘은 계통도에서 고유한 위치를 가지면서도 여러 문제, 기법, 자료구조, 분야 및 다른 알고리즘과 연결될 수 있습니다.

## 탐색 경험

처음에는 다섯 개의 핵심 가지로 이루어진 간결한 계통도만 나타납니다. 노드를 선택하면 하위 분류가 오른쪽으로 펼쳐지고, 실제 알고리즘을 선택하면 그 알고리즘에서 파생되거나 발전한 알고리즘을 확인할 수 있습니다.

알고리즘 상세 화면에서는 개요, 복잡도, 동작 방식, 장단점, 활용 사례, 역사, 의미 관계, 구현 예제와 참고 자료를 함께 제공합니다. 검색을 통해 알고리즘뿐 아니라 문제, 설계 기법, 자료구조와 응용 분야까지 찾을 수 있으며, 검색 결과의 계통 경로가 자동으로 펼쳐집니다.

한국어와 영어를 모두 지원하고 라이트 모드와 다크 모드를 선택할 수 있습니다. 넓게 확장되는 계통도는 이동과 확대·축소를 통해 캔버스처럼 탐색할 수 있습니다.

## 시각적 방향

Algoria는 마인드맵이나 원형 네트워크 그래프가 아니라 생물 계통도와 분류도에 가까운 구조를 지향합니다. 명확한 세대, 직각 연결선, 절제된 색상, 읽기 쉬운 타이포그래피와 넓은 여백을 사용해 계통도 자체가 화면의 중심이 되도록 설계되었습니다.

## 프로젝트 성격

Algoria는 HTML, CSS, Vanilla JavaScript로 구성된 완전한 정적 웹사이트입니다. 서버나 데이터베이스 없이도 알고리즘 계통도, 의미 관계, 상세 정보와 검색 경험을 제공하는 것을 목표로 합니다.
